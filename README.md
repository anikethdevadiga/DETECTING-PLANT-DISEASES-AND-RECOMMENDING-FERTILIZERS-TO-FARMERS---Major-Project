# DETECTING-PLANT-DISEASES-AND-RECOMMENDING-FERTILIZERS-TO-FARMERS
– Built a computer vision model using CNN to analyze 5000+ plant leaf images and detect diseases with high accuracy.
– Integrated a rule-based recommendation engine to recommend fertilizers based on crop type and soil conditions.
– Applied OpenCV and NumPy for image preprocessing and dataset preparation.
– Enhanced agriculture decision-making by providing a unified disease detection and fertilizer advisory system.
